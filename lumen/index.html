Lumen Mail

Mail, straight from this device. No servers of ours.

Lumen connects directly to iCloud Mail and NetEase Mail (163, 126, yeah.net, and 188). You can add more than one mailbox; each app-specific password or authorization code stays in the system Keychain. Reader mode cleans up a cluttered letter. Summary and English-to-Chinese translation run on the device. Pictures stored on another server are not loaded, so a tracking image cannot report that you opened the message. There is no server of ours.
